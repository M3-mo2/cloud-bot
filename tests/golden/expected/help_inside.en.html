❓ Help

CloudBot runs your code safely in an isolated sandbox — you never need to touch a server.

A workspace is your private sandbox: its own files, packages, processes, ports and terminals, isolated from every other user. Everything you do to it stays inside it.

Inside a workspace you can browse and edit files, run commands and jobs, open a terminal, install packages, publish tunnels, and inspect ports, metrics, processes and archives.

You can keep several workspaces and open several terminals in each. A terminal is live until you close it or it sits idle long enough — then it ends and you can open a new one.

Terminal size

The chat decides how much of the screen you see. To change the terminal itself, run stty cols N rows M inside the shell (stty size reads the current size).

Commands
  • /start — open the menu
  • /settings — language & preferences
  • /help — this message

Your files are private to you. Nothing is shared between users.
